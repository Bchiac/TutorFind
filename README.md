# TutorApp - Ứng dụng quản lý lớp học gia sư

TutorApp là ứng dụng Android hỗ trợ người dùng tìm kiếm, đăng ký và theo dõi lớp học với gia sư. Ngoài ra, quản trị viên có thể duyệt yêu cầu và theo dõi các lớp học đăng ký.

## 📱 Tính năng chính:
- Đăng ký / Đăng nhập bằng Email (Firebase Auth)
- Tìm kiếm danh sách gia sư
- Đăng ký lớp học, theo dõi trạng thái (Chờ duyệt, Đã duyệt, Từ chối)
- Quản trị viên: duyệt/xóa các yêu cầu lớp học
- Đổi mật khẩu, đăng xuất
- Giao diện tối ưu trên Android (Jetpack Compose)

## 🧰 Công nghệ sử dụng:
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Firebase Storage (dự phòng)
